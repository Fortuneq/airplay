## 🚀 Размещение на хостинге

### Вариант 1: GitHub Pages

#### Шаг 1: Создание репозитория
```bash
# Инициализация Git в папке проекта
cd /path/to/Airplay
git init

# Добавление файлов
git add .
git commit -m "Initial commit: Airplay Telegram Mini App"

# Создайте репозиторий на GitHub и подключите его
git remote add origin https://github.com/ВАШ_USERNAME/airplay-game.git
git branch -M main
git push -u origin main
```

#### Шаг 2: Настройка GitHub Pages
1. Перейдите в **Settings** репозитория
2. Найдите раздел **Pages**
3. В **Source** выберите **Deploy from a branch**
4. Выберите ветку **main** и папку **/ (root)**
5. Нажмите **Save**

**Ваша игра будет доступна по адресу:**
`https://ВАШ_USERNAME.github.io/airplay-game/`

### Вариант 2: Netlify (Drag & Drop)

#### Шаг 1: Подготовка архива
```bash
# Создайте ZIP архив со всеми файлами
zip -r airplay-game.zip index.html game.js styles.css manifest.json
```

#### Шаг 2: Деплой
1. Перейдите на [netlify.com](https://www.netlify.com)
2. Нажмите **Deploy manually**
3. Перетащите папку с проектом в область загрузки
4. Дождитесь деплоя

**Получите URL вида:** `https://RANDOM-NAME.netlify.app/`

### Вариант 3: Vercel

#### Через интерфейс:
1. Перейдите на [vercel.com](https://vercel.com)
2. Подключите GitHub репозиторий
3. Настройте автоматический деплой

#### Через CLI:
```bash
# Установка Vercel CLI
npm i -g vercel

# Деплой
cd /path/to/Airplay
vercel

# Следуйте инструкциям в консоли
```

## 🤖 Настройка BotFather

### Шаг 1: Создание бота
1. Откройте Telegram и найдите [@BotFather](https://t.me/botfather)
2. Отправьте команду `/newbot`
3. Введите название бота: `Airplay Game`
4. Введите username: `airplay_game_bot` (должен быть уникальным)
5. Сохраните полученный **API Token**

### Шаг 2: Настройка описания
```
/setdescription
@airplay_game_bot
🎮 Увлекательная аркадная игра! Управляй самолётом, избегай препятствий, собирай монеты и бей рекорды! ✈️

🎯 Особенности:
• Простое управление одним касанием
• Красивая графика и анимации
• Система достижений и магазин
• Сохранение прогресса в облаке

Нажми /play чтобы начать!
```

### Шаг 3: Настройка короткого описания
```
/setabouttext
@airplay_game_bot
Аркадная игра про полёты самолёта с препятствиями. Собирай монеты, бей рекорды! 🎮✈️
```

### Шаг 4: Добавление команд
```
/setcommands
@airplay_game_bot
play - 🚀 Играть в Airplay
help - ❓ Помощь и правила
stats - 📊 Статистика игры
```

### Шаг 5: Настройка изображений
```bash
# Для аватара бота (512x512 px)
/setuserpic
@airplay_game_bot
# Загрузите картинку с самолётом или логотипом игры
```

## 🔧 Устранение неполадок

### Частые проблемы

#### 1. Игра не загружается
**Проблема**: Белый экран или ошибка 404
**Решение**:
- Проверьте правильность URL
- Убедитесь что файлы загружены на хостинг
- Проверьте настройки HTTPS

#### 2. Telegram API не работает
**Проблема**: `Telegram is not defined`
**Решение**:
```html
<!-- Убедитесь что скрипт загружен ПЕРЕД вашим кодом -->
<script src="https://telegram.org/js/telegram-web-app.js"></script>
<script src="game.js"></script>
```

#### 3. Ошибки CORS
**Проблема**: Блокировка запросов
**Решение**:
- Используйте HTTPS хостинг
- Настройте правильные заголовки CORS
- Проверьте настройки домена

#### 4. Тактильная обратная связь не работает
**Проблема**: `HapticFeedback is undefined`
**Решение**:
```javascript
if (tg && tg.HapticFeedback) {
    tg.HapticFeedback.impactOccurred('light');
}
```

#### 5. Данные не сохраняются
**Проблема**: Прогресс теряется
**Решение**:
- Проверьте работу localStorage
- Добавьте Cloud Storage API
- Убедитесь в правильности JSON

### Отладка

#### Проверка в браузере:
```javascript
// Откройте консоль разработчика (F12) и выполните:
console.log('Telegram WebApp:', window.Telegram);
console.log('User data:', tg?.initDataUnsafe?.user);
console.log('Platform:', tg?.platform);
```

#### Проверка манифеста:
1. Откройте DevTools → Application → Manifest
2. Проверьте что все поля заполнены
3. Убедитесь что иконки загружаются

#### Проверка PWA:
1. DevTools → Lighthouse
2. Запустите аудит PWA
3. Исправьте найденные проблемы

- Оптимизируйте анимации (используйте CSS transforms)
