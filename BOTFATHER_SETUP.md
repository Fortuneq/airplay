## 🎯 Создание бота

### Шаг 1: Обращение к BotFather
1. Откройте Telegram
2. Найдите [@BotFather](https://t.me/botfather)
3. Нажмите **Start** или отправьте `/start`

### Шаг 2: Создание нового бота
Отправьте команду:
```
/newbot
```

### Шаг 3: Настройка имени бота
BotFather спросит название бота. Введите:
```
Airplay Game
```
или
```
🎮 Airplay - Авиа Аркада
```

### Шаг 4: Настройка username бота
Введите уникальное имя (должно заканчиваться на 'bot'):
```
airplay_game_bot
```
или
```
airplay_aviation_bot
```

⚠️ **Важно**: Username должен быть уникальным. Если занят, попробуйте варианты:
- `airplay_mini_game_bot`
- `airplane_game_telegram_bot`
- `aviation_arcade_bot`

### Шаг 5: Сохранение токена
BotFather выдаст **API Token**. Сохраните его в безопасном месте:
```
1234567890:ABCdefGHIjklMNOpqrsTUVwxyz123456789
```

## 🌐 Создание Web App

### Шаг 1: Создание приложения
```
/newapp
@ваш_бот_username
```

### Шаг 2: Настройка Web App

#### Title (название):
```
Airplay Game
```

#### Description (описание):
```
Увлекательная аркадная игра где вы управляете самолётом, избегаете препятствий и собираете монеты
```

#### Photo (изображение):
Загрузите скриншот игры размером **640x360 пикселей**

Можно использовать:
- Скриншот главного меню
- Кадр из игрового процесса
- Коллаж из нескольких экранов

#### Demo GIF (опционально):
Загрузите короткий GIF (до 5 сек) показывающий геймплей

#### URL приложения:
```
https://ваш-домен.com/
```

**Примеры доменов:**
- `https://username.github.io/airplay-game/`
- `https://amazing-name.netlify.app/`
- `https://airplay-game.vercel.app/`

## 🎨 Настройка визуальных элементов

### Аватар бота
```
/setuserpic
@ваш_бот_username
```

**Требования к изображению:**
- Размер: **512x512 пикселей**
- Формат: PNG, JPG
- Стиль: яркий, узнаваемый

**Идеи для аватара:**
- Силуэт самолёта на цветном фоне
- Логотип игры с названием "Airplay"
- Мультяшный самолётик
- Иконка с облаками и самолётом

### Изображение для Web App
При создании Web App используйте:
- **Основное фото**: 640x360px - скриншот игры
- **GIF превью**: короткая демонстрация геймплея

## ⚙️ Продвинутые настройки

### Настройка инлайн режима (опционально)
```
/setinline
@ваш_бот_username
```

Placeholder текст:
```
Поделиться игрой Airplay...
```

### Настройка инлайн кнопок
Для команды `/play` можно добавить кнопку:
```javascript
// В коде бота
const keyboard = {
    inline_keyboard: [[
        { text: '🚀 Играть', web_app: { url: 'https://ваш-домен.com/' } }
    ]]
};
```

### Настройка приватности
```
/setjoingroups
@ваш_бот_username
```
Выберите **Disable** если бот только для игры

```
/setprivacy
@ваш_бот_username
```
Выберите **Disable** для получения всех сообщений

- [ ] Описание установлено (полное)

#### Web App:
- [ ] Web App создан

- [ ] Описание приложения добавлено
- [ ] URL приложения корректный
- [ ] Изображение загружено (640x360px)
- [ ] GIF демо загружен (опционально)

#### Команды и интерфейс:
- [ ] Команды настроены
- [ ] Кнопка меню установлена
- [ ] Кнопка Web App работает

### Тестирование бота

#### 1. Базовый тест
1. Найдите своего бота в Telegram
2. Нажмите **Start**
3. Проверьте отображение описания
4. Попробуйте команды

#### 2. Тест Web App
1. Нажмите на кнопку меню с игрой
2. Убедитесь что игра загружается
3. Проверьте работу в полноэкранном режиме

#### 3. Тест на разных устройствах
- [ ] **iPhone/iOS** - проверьте работу
- [ ] **Android** - проверьте работу
- [ ] **Desktop Telegram** - базовая функциональность

### Исправление проблем

#### Проблема: "App not found"
**Решение**: Проверьте URL приложения, убедитесь что сайт доступен по HTTPS

#### Проблема: Игра не загружается
**Решение**: 
- Проверьте статус хостинга
- Убедитесь что все файлы загружены
- Проверьте консоль браузера на ошибки

#### Проблема: Кнопки не отвечают
**Решение**: Пересоздайте Web App с правильным URL
